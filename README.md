# Kiran Majeed | Portfolio Website

A fast, responsive personal portfolio for **Kiran Majeed**, a Full Stack Web Developer who builds business software and websites with **Laravel, PHP, MySQL, WordPress and WooCommerce**.

The site shows who I am, what I can do, the work I have shipped, and how to hire me. It is built with plain HTML, CSS and JavaScript, so it loads quickly and can be hosted anywhere, including GitHub Pages.

## What's Inside

- **Home** with a hero section, about, skills, experience, services, projects preview and a contact section
- **Projects** page with a showcase of real client and product work
- **Services** page covering custom web applications, ERP and accounting systems, and WordPress/WooCommerce stores
- **Coming Soon** page with a launch countdown and an email sign-up box, for upcoming sections

## Highlights

- Dark theme with a purple gradient accent and smooth animations
- Fully responsive, from phones to large desktop screens
- Custom cursor, animated hero and a mobile slide-in menu
- Optimised `.webp` project images for quick loading
- No frameworks or build step. Open `index.html` and it works.

## Tech Stack

- HTML5
- CSS3 (custom properties, Grid, Flexbox, animations)
- Vanilla JavaScript
- Google Fonts: Syne, Space Mono, DM Sans

## Run Locally

1. Download or clone this repository.
2. Open `index.html` in any browser.

For live reload, use the VS Code Live Server extension or run `npx serve` in the project folder.

## Customise

- **Colours and fonts:** edit the variables at the top of `css/style.css`.
- **Projects:** add a new image to `images/portfolio/` and a new card in `projects.html`.
- **Coming Soon launch date:** change the `launch` date in the script at the bottom of `coming-soon.html`.
- **Email form:** connect the Coming Soon form to Formspree, EmailJS or a backend to collect emails.

## Deployment

The site is static, so it can be deployed for free on GitHub Pages, Netlify or Vercel. Upload the folder contents and set `index.html` as the entry point.
